SUSHIL PANEL ERP WEB

LOCAL START:
1. Install Python 3.11+
2. Double-click RUN_ERP.bat
3. Open http://127.0.0.1:5000
4. Login: admin / Admin@123

NETWORK:
This app listens on 0.0.0.0. Find the computer IPv4 using ipconfig.
Other devices on the same Wi-Fi can open http://COMPUTER-IP:5000.

ONLINE:
For access from anywhere, deploy to a hosting/server. Before public production use,
set a strong SECRET_KEY, use HTTPS, PostgreSQL, backups, and a production web server.
Do not expose the development server directly to the internet.
